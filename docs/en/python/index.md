# Python

Python is a high-level, general-purpose programming language designed with readability in mind. It allows programmers to express instructions in a relatively clear form while many lower-level details of the computer are handled behind the scenes. As a general-purpose language, Python can be used for many different types of tasks. It is also free, open source, and cross-platform, which means that it can be used on operating systems such as Windows, macOS, and Linux.

![Python logo](./assets/images/python_logo.svg)

Readability is an important part of Python's design. The language uses indentation to define the structure of code rather than relying on braces or explicit keywords to separate blocks. Python is also dynamically typed, which means that variable types are determined while a program is running rather than being declared explicitly in advance. These characteristics influence how Python code is written and organized, although we will examine them in more detail when they become relevant.

Readable syntax does not mean that every Python program is simple. Programs can become complex regardless of the language being used. Rather than guaranteeing simplicity, Python aims to make the code itself easier to read and understand, allowing many ideas to be expressed without a large amount of additional syntax.

## Where is Python used?

Python is used across many areas of IT. It can be used to build web applications, desktop software, and command-line tools. It is also widely used for automation, data analysis, scientific computing, and machine learning. Python can also interact with hardware and is used in areas such as electronics and robotics.

These areas involve different kinds of problems, but Python can be applied in each of them. This makes knowledge of the language useful in a variety of technical contexts.

## How does Python work?

Python programs are written as source code. Source code is the human-readable text in which a programmer expresses the instructions that make up a program. Python is an interpreted language, which means that a Python interpreter is responsible for processing and executing the program.

Python also supports interactive use. Individual instructions can be entered and their results observed immediately without creating a complete program first. This is useful for experimenting with the language, checking how something behaves, and testing small ideas.

Python provides built-in functionality for many common operations and can be extended with additional libraries. Libraries contain existing code that programs can use to perform particular tasks without requiring programmers to write every piece of functionality themselves.
