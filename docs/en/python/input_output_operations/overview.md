# Overview

Inputs and outputs operations provide the foundation for communication between Python programs and their users. These concepts establish how programs display information, receive user input, and present values in a clear and readable form.

The **Inputs and Outputs Operations** module develops from displaying basic values and controlling console output, through reading and converting user input, to formatting text and numerical values. It establishes the techniques needed to create programs that communicate information accurately and present results effectively.

**Level 1** introduces the foundations of console input and output. It explains the **`print()` function**, including separators, line endings, and escape characters, and introduces the **`input()` function** for receiving user input. It then develops **numerical input conversion** using `int()` and `float()` and introduces **basic string formatting** with f-strings and the `%` operator.

Together, these concepts provide a foundation for creating Python programs that can **receive information, process numerical input, and display clear, readable results**. They prepare learners for more advanced formatting techniques and more structured interaction with users.
