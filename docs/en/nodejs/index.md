# Node.js

JavaScript is commonly associated with web browsers, but it can also be used outside them. **Node.js is a JavaScript runtime environment** that allows JavaScript programs to run outside the browser.

![Node.js logo](./assets/images/nodejs_logo.svg)

The distinction between a **programming language** and a **runtime environment** is important. JavaScript defines how we write programs, while a runtime environment provides what is needed to execute them. Node.js provides this environment outside the browser and includes features for working with the file system, the operating system, and network connections.

Node.js therefore extends where we can apply our JavaScript knowledge and the kinds of programs we can create with it. Like other technologies, it is not the best choice for every task. Understanding what an environment provides, what limitations it has, and when it is appropriate to use it is an important part of learning how different technologies work together.
