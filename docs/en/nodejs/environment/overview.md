# Overview

A Node.js development environment provides the tools and organization needed to create, run, and maintain JavaScript programs outside the web browser. The Node.js runtime executes JavaScript code, development tools provide a workspace for creating and editing it, project folders organize related files, and source files preserve JavaScript code. As projects grow, understanding how these components work together provides a foundation for using more advanced development tools and managing different Node.js environments.

The **Environment** module develops from installing Node.js and understanding the components of a basic development environment to working with more advanced environment configurations. It establishes how the Node.js runtime, development tools, execution workflows, project organization, and JavaScript source files work together to support Node.js development.

**Level 1** introduces the foundations of a Node.js development environment. It covers **installing Node.js**, checking that the runtime is accessible through the system `PATH`, and understanding the role of the Node.js runtime within the development environment. It then explains the differences between **text editors, code editors, and IDEs**, **interactive and script workflows**, **basic project organization**, including project folders and subfolders, and the naming, purpose, and encoding of **JavaScript source files**.

Together, these concepts provide a foundation for creating and working within a Node.js development environment with greater confidence. They support a progression from setting up a working Node.js installation and choosing development tools to organizing projects, working with JavaScript source files, and understanding more advanced environment configurations in later levels.
