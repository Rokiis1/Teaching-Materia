# Overview

A Node.js development environment provides the tools, project structure, and configuration needed to create and run JavaScript programs outside the web browser. The Node.js runtime executes JavaScript code, development tools provide a workspace for creating and editing it, project folders organize related files, and the process environment can provide configuration to a running program.

The **Environment** module develops from setting up a basic Node.js development environment to understanding the environment of a running Node.js program. It establishes how the Node.js runtime, development tools, execution workflows, project organization, source files, processes, and environment variables work together to support Node.js development.

**Level 1** introduces the foundations of a Node.js development environment. It covers **installing Node.js**, checking that the runtime is accessible through the system `PATH`, and understanding the role of the Node.js runtime within the development environment. It then explains the differences between **text editors, code editors, and IDEs**, **interactive and script workflows**, **basic project organization**, including project folders and subfolders, and the naming, purpose, and encoding of **JavaScript source files**.

**Level 2** moves from the development environment to the environment of a running Node.js program. It introduces the **Node.js process** and **process environment**, explores information available through the global `process` object, and explains how **environment variables** can provide configuration without changing the JavaScript source code. It then shows how environment variables are supplied, read and converted through `process.env`, and grouped in **`.env` files**, together with basic practices for keeping local configuration and secrets outside version control.

Together, these levels establish a progression from preparing a Node.js development environment to understanding how configuration reaches a running application. Later levels can build on this foundation with more advanced approaches to organizing, validating, and managing application configuration and Node.js versions across projects.
