# Overview

**Code Quality and Formatting** focuses on keeping source code consistent, readable, and maintainable through automated development tools. The module introduces the separate roles of code analysis and formatting and explores how these responsibilities fit into a JavaScript development workflow.

The module begins with **ESLint** and **Prettier** as the foundation for checking code quality and applying consistent formatting. It covers how these tools are configured, how files can be included or excluded from processing, how linting and formatting can work independently or together, and how the resulting workflow can be integrated with project commands and development environments.

As the module progresses, this foundation can be extended with additional rules, configurations, and plugins for more specialized project requirements. This allows code-quality tooling to develop alongside the JavaScript projects that use it.
