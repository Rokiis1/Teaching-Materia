# Overview

**Express Fundamentals** introduces the basic structure of an Express application and shows how Express provides higher level APIs for working with HTTP concepts introduced previously. Instead of manually inspecting requests and constructing responses with the built-in Node.js `http` module, Express provides application methods for defining routes, handling requests, and sending responses, establishing the foundation for the Express topics that follow.

**Level 1** introduces the essential parts of an Express application, including defining routes, handling incoming request data, and sending different types of responses. It also introduces basic request body processing and demonstrates how HTTP requests can be tested from the command line. These concepts establish the request and response flow that later Express topics build upon.

The module also establishes a practical development workflow for running and testing an Express application while it is being developed. Together, the concepts introduced in **Level 1** provide the foundation needed to begin working with the Express request handling flow. **Middleware Level 1** builds on this foundation by introducing how middleware processes requests as they move through an Express application.
