# Overview

**API Fundamentals** introduces the basic concepts needed to understand how APIs allow different parts of software to interact. APIs provide defined interfaces through which applications, services, and other software components can access functionality provided by another part of a system.

The module begins by establishing what an **API (Application Programming Interface)** is and how software interacts through one. It introduces the roles involved in API communication, the functionality an API can expose, and the boundaries APIs create between different parts of software. These foundations prepare for later levels that explore API technologies and design concepts in greater detail.

**Level 1** introduces the relationship between a **consumer**, an API, and a **provider** and explains how APIs expose operations through defined interfaces. It also shows that APIs can exist across different software boundaries, including applications, services, libraries, operating systems, databases, and frameworks. The level concludes by introducing **REST**, **GraphQL**, **SOAP**, and **gRPC** as examples of different approaches to communication between applications and services.

Together, these concepts establish the foundation needed to understand how APIs connect software and provide a starting point for studying more specific API technologies and design practices in later levels.
