# Overview

**JSON Web Tokens (JWTs)** are a standardized, compact, JSON-based format for representing claims, defined by [RFC 7519](https://www.rfc-editor.org/rfc/rfc7519). The format provides a common structure for organizing claims and supports cryptographic mechanisms for protecting their integrity and confidentiality. JWTs can be used in different security contexts, with their specific processing and validation requirements depending on the systems and protocols involved.

This topic is organized into two levels. [Level 1](./1_level/1_level_jwt.md) introduces JWT structure, claims, and the fundamentals of validation and secure handling. [Level 2](./2_level/2_jwt.md) explores JWT construction, encoding, cryptographic protection, and validation requirements in greater technical detail.
