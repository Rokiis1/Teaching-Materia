# Overview

**Token types** classify security tokens according to their intended purpose within authentication, authorization, and session management. This classification helps distinguish the different roles tokens perform in software systems and how those roles influence their use.

Although multiple token types may be used within the same application, they are not necessarily interchangeable. Each type serves a particular purpose, and its appropriate use depends on the systems and security requirements involved. Understanding these differences provides a foundation for examining how tokens are issued, exchanged, and managed.

This topic is organized into two levels. [Level 1](../token_types/1_level/1_level_token_types.md) introduces the common token types and examines their purposes, intended recipients, and practical usage through examples. [Level 2](../token_types/2_level/2_token_types.md) explores their relationships, lifecycle management, usage constraints, and security considerations in greater detail.
